Robust Prompt Tuning for Vision–Language Models

Can small changes to prompts improve robustness while preserving clean accuracy?

Nanyang Technological University

Research with Prof. Yew-Soon Ong

Learning robust prompts

We investigated prompt tuning for vision–language models such as CLIP. By learning a small set of prompts, we aimed to improve adversarial robustness while preserving accuracy on clean inputs and making only limited changes to the pretrained model.

TeCoA [1] and FARE [2] show that adversarial adaptation can improve CLIP’s robustness, but clean accuracy remains a concern. In the reported comparisons, FARE retains more clean accuracy than TeCoA, though it can still fall below the original CLIP. We explored prompt tuning as another way to approach this trade-off.

References

[1] TeCoA · Chengzhi Mao, Scott Geng, Junfeng Yang, Xin Wang, and Carl Vondrick. Understanding Zero-Shot Adversarial Robustness for Large-Scale Models. ICLR, 2023.

[2] FARE · Christian Schlarmann, Naman Deep Singh, Francesco Croce, and Matthias Hein. Robust CLIP: Unsupervised Adversarial Fine-Tuning of Vision Embeddings for Robust Large Vision-Language Models. ICML, 2024. Reported clean and adversarial results.
